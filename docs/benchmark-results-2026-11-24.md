# 고정 세트 진단기 측정 결과 (2026-11-24)

## 측정 범위

- Docker 실험망에서 `fixtures/fixed_set` 30개 시나리오를 진단기별 3회 반복했다.
- 진단기 5종(A, B, C, C-1, C-2), 총 450라운드(진단기마다 90라운드)를 실행했다.
- GLM 진단기는 `opencode-go/glm-5.3-flash`를 사용했다.
- 단계·원인 정확도와 오진 라운드는 정상 채점된 라운드만 대상으로 한다. `invalid` 라운드는 정확도에서 제외했다.
- 고정 세트는 라운드마다 장애 하나를 사용하므로 정확도의 분모는 채점 라운드 수와 같다.

근거 지지율의 분모는 채점 라운드의 인용 근거 수다. 자동 판정이 어려운 근거는 수동 확인 필요로 따로 세며 지지율의 분자에 넣지 않는다. 오진 라운드는 하나 이상의 장애 판정 오류 또는 오탐이 있는 채점 라운드다. 오탐 수는 오탐 라벨 수의 합이다.

## 관찰

- A는 90라운드 모두 채점됐고 원인 정확도는 87/90 (97%)이었다.
- GLM 방식 중 C-1은 가장 많은 88/90라운드가 채점됐고, 원인 정확도는 67/88 (76%)이었다.
- B는 35라운드가 무효였다. 이 중 34건은 진단 출력 형식 오류, 1건은 진단 실행 오류로 기록됐다.
- 전체 450라운드에서 증상 재현과 초기화 확인은 모두 성공했다.

상세 라운드 기록과 전체 HTML 보고서는 시나리오 정답, 점수, 검사 출력을 포함하므로 저장소 밖 `~/netrunner-private/runs`에 보관한다.
